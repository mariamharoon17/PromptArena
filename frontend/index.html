Two scorers, one rubric

Every response is scored twice on the same four dimensions and the same fixed weights. The rule-based scorer is deterministic and fully reproducible. The LLM-as-Judge reads the content and runs at temperature 0, applied equally to all three answers.

The same rubric covers all three modes. Build a Website adds four render checks on top (does the file render, does it hold up at mobile width, does it use semantic landmarks, are the form inputs labelled). Code Assist scores explanations, fixes, tests and refactors exactly as it scores any other answer, so the model you pick is the one that measurably did the better job.

The weighting was designed to counter verbosity bias. Self-preference bias remains a limitation; leave-one-out judging is noted as future work. The Winner badge follows the rule-based score.

Substance35%

Real content: working code, tables, links, concrete figures. Broken or error-filled output scores lower.

Completeness20%

Depth relative to the prompt, with a diminishing-returns plateau so padding earns nothing.

Clarity25%

Readability, sentence length, and whether the answer is structured with lists, headings or line breaks.

Reliability20%

Refusals and broken output are penalised; calibrated, honest uncertainty is rewarded.
