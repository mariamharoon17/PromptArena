Project Overview

AI-assisted coding is transforming how software is built, but how does one tool compare to another?

PromptArena is a web-based benchmarking platform developed as part of an MSc dissertation at Aston University. It provides a systematic, repeatable framework for comparing the performance of three leading AI language models: ChatGPT (OpenAI), Claude (Anthropic) and Gemini (Google) across a range of software development tasks.

The tool addresses a significant gap in existing research: while individual AI tools are widely discussed, rigorous side-by-side comparisons using standardised tasks and objective metrics are rare. PromptArena fills this gap by providing a reusable, extensible evaluation framework.

Methodology

How benchmarking works

Step 01
Prompt Design
Standardised prompts are designed across 5 task categories to ensure fair, repeatable testing.
Step 02
Simultaneous Querying
Each prompt is sent to all 3 AI models simultaneously via their official APIs, ensuring identical conditions.
Step 03
Auto Scoring
Responses are automatically scored across 6 metrics using a heuristic scoring engine built in JavaScript.
Step 04
Storage & Analysis
All results are saved to a SQLite database and can be exported as CSV for further analysis.

Each benchmark run measures: Response Time (ms), Token Usage, Code Correctness, Completeness, Clarity and Error Rate producing an Overall Score out of 100 for each model.
